# Simulador de Tienda

Proyecto realizado en JavaScript que simula un sistema básico de compra y gestión de productos.

El programa comienza con un catálogo de productos que incluye nombre, precio, categoría y disponibilidad de stock. A través de un menú interactivo, el usuario puede realizar diferentes operaciones relacionadas con la compra y administración de productos.

## Funcionalidades

- **Comprar productos:** permite seleccionar productos disponibles y agregarlos al carrito de compras.
- **Consultar stock:** muestra los productos disponibles, sus precios y categorías.
- **Ver productos comprados:** permite consultar los productos agregados al carrito.
- **Eliminar último producto comprado:** permite quitar el último producto agregado al carrito.
- **Aplicar descuentos:** permite aplicar un descuento del 20% a los productos disponibles. Cada producto puede recibir un descuento una sola vez.
- **Salir:** permite finalizar el programa.

## Objetivo

Practicar y reforzar el uso de variables, funciones, ciclos, condicionales, arrays, objetos y clases en JavaScript, mediante el desarrollo de un simulador interactivo de una tienda.
