Simulador de Stock

Proyecto realizado en JavaScript que simula un sistema básico de compra de productos.

El programa comienza con un stock de 30 productos y permite al usuario ingresar la cantidad que desea comprar. Luego muestra el stock restante y pregunta si desea continuar con la compra.

Tecnologías utilizadas
JavaScript
while
if
prompt()
alert()
console.log()
Objetivo

Practicar el uso de variables, ciclos, condicionales y entrada de datos en JavaScript.
